# Kingdoms & Quests

Dit is de opdracht voor week 1 van Java OOP 2.

Voor deze opdracht maak ik een kleine game genaamd Kingdoms & Quests.

In de game zijn er verschillende characters:
- Warrior
- Mage
- Archer

Ook zijn er verschillende quests die de speler kan doen om XP te verdienen.

Voor deze opdracht moet ik:
- Een use case diagram maken
- Een class diagram maken
- De applicatie maken in Java

Bij deze opdracht ga ik onder andere werken met inheritance en abstract classes.
