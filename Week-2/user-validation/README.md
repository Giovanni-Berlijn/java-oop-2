# User Validation

Dit is de opdracht voor week 2 van Java OOP 2.

Voor deze opdracht maak ik een user validation module.

De module kan gebruikers controleren op:
- Wachtwoord
- Minimumleeftijd
- E-mailadres
- Gebruikersnaam

De developer kan zelf kiezen welke validatieregels gebruikt worden.

Voor deze opdracht moet ik:
- Een use case diagram maken
- Een class diagram maken
- Een activity diagram maken
- De applicatie maken in Java

Bij deze opdracht werk ik onder andere met interfaces, validatie, exceptions en opslag van gebruikers.
